# BMC Food : site de démonstration

Site statique (HTML/CSS/JS, sans build) : visite en vol continu au défilement, carte et infos de BMC Food, Cité Mixta, IDA (Point E), Dakar.

- `index.html` : la page
- `assets/js/content.js` : textes, prix et rythme du vol
- `frames/` : images du vol vidéo + `manifest.js`

Déploiement Vercel : importer le dépôt, framework « Other », aucune commande de build, dossier de sortie = racine.
